# 产品出海市场分析

## 产品快照

- 产品名称：产品出海市场分析。
- 产品类型：以 Codex、ChatGPT app 等 Agent 为主要入口的 Superleads Skill Suite 独立分析路线；完整交付可导出为 XLSX/CSV。
- 一句话定义：为一项明确产品和目标市场整理可追溯的市场、准入、税费、出口要求与物流事实矩阵，供国际贸易从业者自行判断。
- 入口路线：`产品 + 目标国家/地区 + 贸易与运输前提 -> 产品出海市场分析 -> 市场与准入信息矩阵`。

## 用户与问题

- 主要用户：任意出口国/地区的国际贸易卖家、采购商及其业务支持人员。
- 当前痛点：市场趋势、价格参考、合规、关税、出口限制、运输与申报节点散落在不同来源，且产品属性、原产地、起运地和目的国经常被错误混为一谈。
- 现有 Superleads 路线：批量客户开发解决“按用户定义的 B2B 范围找哪些客户”；单一客户背调解决“一个指定对象是谁、在做什么”。二者均不承担通用产品的市场与准入研究。

## 已确认定位

- 本功能与批量客户开发、单一客户背调平行，绝不自动创建 Candidate、联系人、客户类型、客户名单或市场进入建议。
- 产品是否进入某个国家/地区、是否值得进入、如何报价、开发哪些客户，均由用户自行判断；系统只提供带条件和来源的客观参考。
- 线上 B2B/B2C 页面、电商页面、公开报价、价格指数与期货信息均可作为市场和价格参考，但不定义传统外贸 B2B 的目标客户群体。
- 批量客户开发的客户选择合同仍是客户类型与客户范围的唯一权威。市场分析中的渠道、价格、术语、旺季和市场结构只能作为下一次客户开发的可选输入，不能自动继承。

## 核心价值

- 把分散的国际贸易事实按产品条件、市场条件、运输条件和时间条件放入一套可审计的信息矩阵。
- 让用户先看表格化事实、限制和待确认项，需要复核时再看到原始来源和日期。
- 面向全品类，而不是将消费品、电商或集装箱运输当作默认世界。

## 首个闭环

1. 用户提供一个产品版本、目标国家/地区和贸易前提。
2. 系统建立产品属性与监管触发项，发现资料缺口时显式停留在待确认状态。
3. 系统按市场信号、准入税费、出口要求、运输申报四条事实链采集来源并交叉复核。
4. 用户收到以 Markdown 信息矩阵为主、可导出 XLSX/CSV 的客观报告。

## MVP 边界

本版本支持：单一明确产品版本、单一具体目的国的可追溯研究；欧盟等地区可作为市场观察范围，但法规、税费、港口、语言、EPR 和清关要求必须按具体目的国落地。

本版本不支持：自动法律/关税/认证判定，自动生成市场进入建议、报价建议、采购意愿、客户推荐、投资或期货交易建议，或者无来源的“最新”结论。
