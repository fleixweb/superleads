# 产品出海市场分析：真实来源采集策略（Slice 8）

本文件冻结 `产品出海市场分析` 的真实来源采集策略。它不是代码，不联网采集，不冻结任何当前法规、税率、价格或物流事实；它只定义：**未来真正做报告时，哪些来源可以用、怎么找、怎么打开、怎么记录、怎么降级、怎么交叉验证。**

一句话策略：**搜索只找线索，打开来源才算观察；官方和原始来源优先，平台和报告摘要只做参考；缺能力或缺资料时宁可写待确认，也不猜结论。**

## 1. Slice 8 边界

| 项目 | 本轮决定 |
|---|---|
| 目标 | 冻结真实来源采集的来源类型、优先级、采集流程、能力门槛、降级规则和样本路径 |
| 当前仍不做 | 不写代码、不新增 source registry、不联网、不查询最新税率/法规/价格/趋势 |
| 适用对象 | 未来 Skill、validator、audit、EvidenceCard、SearchLog、Source/Observation、Markdown/XLSX 交付 |
| 关键边界 | 不把搜索摘要、外部模型摘要、付费报告摘要、前序 Skill 摘要写成已核实事实 |

## 2. 真实来源采集总流程

| 步骤 | 产物 | 说明 |
|---:|---|---|
| 1 | 冻结 Brief | 明确产品版本、目标国家/地区、默认或指定出口申报国、原产国状态、起运地状态 |
| 2 | 能力预检 | 记录 `search.web`、`source.open`、`document.extract`、`browser.render` 等能力是否可用 |
| 3 | 采集计划 | 按事实域拆查询组：产品资料、趋势、价格、目的国准入、税费、出口国要求、物流、外部因素 |
| 4 | 搜索线索 | 搜索结果只进入候选线索，不产生已核实事实 |
| 5 | 打开来源 | 只有实际打开网页/PDF/官方页面/用户文件并抽取可定位内容，才生成 Observation |
| 6 | 证据卡 | 每条可用信息写入 EvidenceCard，包含来源、定位、日期、适用条件、能支持和不能支持什么 |
| 7 | 交叉复核 | 六个 Skill 互证，冲突保留，过期或不匹配降级 |
| 8 | 矩阵交付 | 只从 EvidenceCard、Gap、Conflict、未执行记录生成 Markdown/XLSX 行 |

## 3. 能力门槛与降级

| 能力状态 | 可以做什么 | 不能做什么 | 用户可见结果 |
|---|---|---|---|
| 有 `search.web`，无 `source.open` | 找候选来源、列采集计划 | 不能写已核实事实 | `候选线索 / 待打开来源` |
| 有 `source.open`，无 `search.web` | 打开用户给的 URL 或已知公开来源 | 不能自然扩展来源覆盖 | `基于用户给定来源的局部分析` |
| 无 `document.extract` | 只能记录 PDF/文件待抽取 | 不能把 PDF 内容写成已核实字段 | `文件待抽取 / 来源受限` |
| 无 `browser.render` | 可打开静态 HTML | 不能确认动态页面可见内容 | `动态页面待渲染复核` |
| Google Trends 无法导出/访问 | 不执行趋势采集 | 不能写趋势上升/下降 | `未执行 / 数据待采集` |
| 官方来源无法打开 | 可保留搜索线索或专业二级解释 | 不能写官方已核实 | `来源受限 / 待专业确认` |

能力不足时不补猜。若既没有搜索能力，也没有用户给定 URL/文件，只能输出采集计划和资料清单。

## 4. 来源优先级总表

| 事实域 | 第一优先来源 | 第二优先来源 | 只能作参考/线索 | 不得作为事实 |
|---|---|---|---|---|
| 产品身份与技术参数 | 产品官网、产品手册、TDS、铭牌/标签照片、用户提供技术文件 | 公开目录、测试报告、认证文件 | 经销商页面、平台商品页 | 搜索摘要、模型总结 |
| 原产地/起运 | COO、发票、提单、装箱单、出口报关单 | 产品页 Production/Made in、制造商证书、工厂资料 | 公司介绍、工厂地址 | 由办公室/仓库/常用港口推断 |
| Google Trends | Google Trends 导出或可复核页面 | 同义词/当地语言关键词复核 | 第三方趋势截图 | 把趋势摘要当销量 |
| 市场规模/行业资料 | 官方统计、海关统计、行业协会、可读取公开报告 | 咨询机构公开摘要、行业媒体 | 付费墙摘要 | 搜索摘要里的数字 |
| 线上价格 | 平台商品页、B2B/B2C 公开报价、品牌零售价、公开目录价 | 行业报价、指数、交易所数据 | 不可比规格价格 | 无规格/币种/日期价格 |
| 节日/季节 | 官方节假日、行业采购周期公开来源 | 零售日历、协会说明、历史趋势 | 社媒/媒体经验文章 | 直接判断旺季 |
| 目的国准入 | 目的国主管部门、官方法规库、海关、标准机构 | 认证机构、律师/报关行公开解释 | 博客/媒体解释 | 无来源的“无需认证” |
| 进口税费 | 官方税则、海关裁定、贸易救济/反倾销官方页面 | 报关行解释、税则工具 | 第三方税率聚合页 | 模型记忆/搜索摘要 |
| 出口国要求 | 出口申报国海关、商务/贸易/检验检疫/管制主管部门 | 报关行/行业协会解释 | 论坛/经验贴 | 原产国自动等同出口国 |
| 物流与预申报 | 海关、港口、机场、铁路/口岸、承运人官方规则 | 货代公开说明、班轮/航司信息 | 物流经验文章 | 无条件承诺时效 |
| 近期外部因素 | 政府公告、海关/港口公告、制裁清单、权威新闻、灾害/气象机构 | 行业媒体、协会预警 | 社交媒体线索 | 无日期“最新影响” |

## 5. 各事实域采集策略

### 5.1 产品资料与技术触发项

| 要采集 | 最低来源要求 | 必须记录 | 降级规则 |
|---|---|---|---|
| 型号 / SKU / Design No. | 产品页、手册、标签、证书 | 来源定位、观察日期、适用型号 | 型号不一致则有冲突待复核 |
| 材质 / 成分 / 规格 | 产品页、TDS、BOM、标签 | 单位、范围、版本 | 未见辅料/BOM 不得写全成分 |
| 电池 / 液体 / 粉末 / 磁性 / 危险品 | TDS、SDS、UN38.3、包装说明 | 化学体系、容量、UN 情形、包装状态 | 缺文件则待技术资料确认 |
| 食品接触 / 皮肤接触 / 儿童用品 / 农产品 | 产品说明、标签、检测/合规文件 | 触发条件和适用市场 | 不能写无需认证 |
| 大宗/散杂/RoRo/超限 | 规格书、件重件尺、包装/运输要求 | 件重、尺寸、装卸要求 | 缺件重件尺则物流待确认 |

### 5.2 Google Trends 与长期需求信号

| 要采集 | 策略 |
|---|---|
| 关键词 | 英文、当地语言、行业通用名、消费端名称、B2B 技术名分开测 |
| 时间范围 | 尽可能 2004 年至今；实际可取得时间如实写 |
| 地区 | 按目标国家/地区，不把全球趋势代替当地趋势 |
| 指标口径 | 固定写“相对搜索兴趣，不等于销量、进口量、GMV 或采购需求” |
| 输出 | 上升/下降/波动/平稳/数据不足/未执行，必须带关键词和导出日期 |
| 交叉验证 | 与公开统计、行业报告、价格和季节信号并列，不互相补空 |

### 5.3 公开市场资料与价格参考

| 来源 | 适用 | 必填口径 | 不得推导 |
|---|---|---|---|
| B2B 平台/电商平台 | 标准化可线上展示产品 | 规格、币种、税/运费、卖家地区、观察日期 | 成交价、传统外贸采购价 |
| 品牌/零售页 | 消费品、服装、礼品、配件 | 尺码、颜色、促销、含税/不含税、日期 | 工厂目标价、批发价 |
| 公开报价/目录价 | 工业品、项目品、零部件 | 规格、交货条件、币种、日期 | 最终合同价 |
| 期货/指数 | 金属、能源、粮食、部分农产品 | 交易所、合约月、交割地、单位、币种、日期 | 现货出口价、投资建议 |
| 行业报告摘要 | 市场规模/趋势线索 | 可见内容、报告年份、口径限制 | 付费墙内数字 |

价格采集必须先判断“可比规格”。规格不可比时可以保留为初步参考，但不能汇总成价格区间结论。

### 5.4 目的国准入与进口税费

| 采集对象 | 第一优先来源 | 必填条件 | 禁止升级 |
|---|---|---|---|
| 认证/安全 | 目的国主管部门、官方法规库、标准机构 | 产品属性、适用标准、日期、覆盖范围 | 产品已经合规 |
| 标签/包装 | 主管部门、海关、消费者保护机构 | 语言、位置、内容、产品类别 | 网页信息=实物标签合规 |
| 食品/农产品/检疫 | 农业、食品、检疫主管部门 | 原产国、品种、处理方式、冷链 | 未见检疫证就判断可进口 |
| 危险品/锂电运输 | 交通/危险品主管部门、承运规则 | UN 情形、SDS、UN38.3、包装 | QCVN/普通测试=UN38.3 |
| 税则/关税 | 官方税则、海关裁定、贸易救济页面 | HS/HTS、原产国、日期、税基、附加税 | 候选税号=最终税率 |

税费采集必须拆成：候选税号、归类缺口、基础税率、优惠/协定、贸易救济/附加税、其它税费、税基、有效日期。

### 5.5 出口国要求

| 采集对象 | 策略 |
|---|---|
| 出口申报国 | 以 Brief 中 `export_declaration_country` 为准；默认中国也必须可见可改 |
| 出口许可/管制 | 查出口申报国主管部门、海关、商务/贸易主管部门、两用物项清单 |
| 商检/检验检疫 | 查出口申报国海关/检验检疫/农业食品主管部门 |
| 危险品/化学品 | 查出口侧危险品、化学品、包装和运输申报规则 |
| 农产品/食品/花卉/茶叶 | 查检疫、植检、农残、卫生证、冷链要求 |
| 大宗商品 | 查出口许可证、配额、质量标准、商检和特定政策 |

原产国、出口申报国、卖方所在国、实际起运国必须分开。原产国已知也不能自动得出出口国要求。

### 5.6 物流、路线与申报节点

| 采集对象 | 来源策略 | 用户可见边界 |
|---|---|---|
| 常用港口/机场/口岸 | 港口/机场/承运人/货代公开资料 | 常用节点参考，不是固定起运港 |
| 海运 FCL/LCL | 船司/港口/货代公开说明 | 常见区间，不是承诺交期 |
| 空运/快递 | 航司/快递/危险品规则 | 受货型、文件、包装、账号和承运条件影响 |
| 铁路/公路 | 班列、口岸、海关/物流公开资料 | 候选路径，不保证可走 |
| 散货/散杂/RoRo | 港口能力、船型、装卸要求、货代/船代资料 | 需件重件尺、货量、装卸条件 |
| 冷链/罐箱/危化 | 港口设备、危险品规则、SDS、温控要求 | 需专业确认和承运确认 |
| 法定预申报 | 海关/主管部门官方来源 | 与船司截单、仓库截货、港口截关分开写 |

运输时效只能写“常见区间 + 来源 + 条件 + 观察日期”，不能写承诺交期或最佳运输方式。

### 5.7 近期外部因素

| 因素 | 采集来源 | 输出边界 |
|---|---|---|
| 政治/制裁/贸易限制 | 政府公告、制裁清单、海关/贸易主管部门、权威新闻 | 必须有日期；不做投资/政治判断 |
| 战争/冲突 | 政府旅行/贸易公告、权威新闻、航运/保险公告 | 只写对运输、保险、清关、汇率等可能影响 |
| 自然灾害/天气 | 气象、灾害、港口/机场公告 | 不写无来源“严重影响” |
| 金融/汇率/危机 | 央行、官方统计、权威金融数据 | 不做汇率预测 |
| 假期/罢工/暑假 | 官方节假日、港口/工会/行业公告 | 写操作窗口影响，不推导产品旺季 |

## 6. Query Plan 设计

每个事实域都应生成可审计查询组，而不是让模型自由搜索。

| 字段 | 说明 |
|---|---|
| `query_group_id` | 趋势、价格、准入、税费、出口、物流、外部因素等 |
| `purpose` | 为什么搜这组，不得泛泛写“了解市场” |
| `query_language` | 英文、目的国语言、出口国语言、中文等 |
| `query_terms` | 产品通用名、技术名、型号、HS 候选、法规关键词 |
| `must_open_source_types` | 官方、产品页、PDF、税则、平台价、港口/承运人等 |
| `reject_if_only_snippet` | 默认 true；只有摘要就不能入已核实 |
| `expected_matrix_sheet` | 对应 12 张工作表 |
| `fallback` | 找不到来源时写什么状态 |

## 7. Source / Observation 记录规则

| 字段 | 必填 | 说明 |
|---|---|---|
| 来源名称 | 是 | 用户可理解的机构/网页/文件名 |
| 来源类型 | 是 | 官方、产品页、PDF、平台、报告、新闻、用户文件等 |
| URL/文件名 | 是 | 公开 URL 或安全显示文件名；不得本地路径 |
| 访问边界 | 是 | 公开、用户提供、来源受限、付费墙、动态页面等 |
| 观察日期 | 是 | 本轮查看日期 |
| 来源日期/生效日期 | 条件必填 | 法规、税费、报告、新闻、价格、趋势必须尽量记录 |
| 定位 | 是 | 页码、章节、表格、标题、页面区域、查询参数等 |
| 原文摘录/可见内容 | 是 | 用于支持字段，不能只有总结 |
| 支持字段 | 是 | 该来源直接支持什么 |
| 不支持字段 | 是 | 不能升级成什么结论 |

用户可见来源表只能展示安全来源名称、公开 URL、文件名、日期和限制；不得展示本地路径、hash、内部 ID、搜索 query token。

## 8. “最新”使用规则

| 信息类型 | 可称“最新”的最低条件 | 默认复核建议 |
|---|---|---|
| 关税/贸易救济/出口管制 | 官方来源打开，有有效日期或观察日期，且报告写明截至日期 | 交付当日或短周期复核 |
| 法规/认证/标签 | 官方来源打开，有发布日期/生效日期/观察日期 | 重要交付前复核 |
| 价格/平台挂牌 | 有观察日期、规格、币种、税运费条件 | 7-14 天内更可靠，过期写待复核 |
| Google Trends | 有导出/观察日期、关键词、地区、时间范围 | 每次报告重新导出或标旧数据 |
| 物流时效/港口节点 | 有来源日期或观察日期、路线条件 | 船期/航班/拥堵需短周期复核 |
| 新闻/外部因素 | 有事件日期和发布来源 | 只对明确时间窗口有效 |
| 行业报告 | 有报告年份和可见范围 | 不能称实时最新，只能称报告期信息 |

没有来源日期或观察日期时，不得写“最新”。可以写“已观察，日期未见，需复核”。

## 9. 首批样本来源路径

### 9.1 Xing Heng `48V20Ah` LiFePO4 电池包：越南来源线索，出口美国

| 事实域 | 采集来源类型 | 必须保留的边界 |
|---|---|---|
| 产品参数 | 制造商产品页、证书/测试报告、产品手册 | 只支持型号、规格、QCVN 范围；不支持 UN38.3/SDS |
| 电池运输 | 美国危险品运输法规、锂电运输文件、SDS、UN38.3、包装资料 | 缺 UN38.3/SDS/包装则不能判断可出运 |
| 税费 | 美国官方税则、海关归类/裁定、贸易救济来源 | `8507.60.00` 只能候选；最终税率待专业确认 |
| 出口国要求 | 以实际出口申报国为准；若用户确认越南，再查越南出口侧主管来源 | 不把越南制造线索自动当出口申报国 |
| 物流 | 起运港/机场、FCL/LCL/空运/快递、危险品订舱要求、美国预申报 | 不默认海防港；不写普通货或最佳方式 |
| 市场/价格 | Google Trends、同电压/容量/化学体系公开价格、行业资料 | 不写销量增长或推荐价格 |

### 9.2 UNIQLO Men's Corduroy Overshirt `470177`：中国 Production，出口美国

| 事实域 | 采集来源类型 | 必须保留的边界 |
|---|---|---|
| 产品资料 | UNIQLO 产品页、实物标签、BOM、规格/克重资料 | 网页 Body/Trim 不等于全成分；实物标签待核验 |
| 目的国标签 | 美国纺织标签、护理标签、原产地标识主管来源 | 网页洗护/RN 不等于实物标签合规 |
| 税费 | 美国官方税则、海关归类/裁定、贸易救济来源 | `6205.20.20` 只能候选；最终归类待专业确认 |
| 出口国要求 | 若出口申报国确认为中国，再查中国出口侧主管来源 | Production: China 不等于出口申报国和起运港 |
| 物流 | 中国到美国 FCL/LCL/空运/快递候选路线、预申报节点 | 不默认上海/宁波/深圳等起运港 |
| 市场/价格 | 服装趋势、公开零售价/平台价、季节和节日窗口 | 零售价不等于外贸成交价或目标价 |

## 10. Source Pack 机制草案

未来不应一个国家一个国家硬编码，而应维护可扩展的 `Source Pack` 概念。

| Source Pack 类型 | 包含什么 | 不包含什么 |
|---|---|---|
| 目的国准入 Pack | 主管部门、法规库、标签/包装、产品安全、检疫、危险品入口 | 不存具体产品结论 |
| 目的国税费 Pack | 官方税则、海关裁定、贸易救济、VAT/GST 入口 | 不存最终税率 |
| 出口国 Pack | 海关、商务/贸易、检验检疫、出口管制、许可证入口 | 不把原产国自动当出口国 |
| 物流 Pack | 港口/机场/口岸、承运人、海关预申报、常见路线入口 | 不承诺时效 |
| 市场信号 Pack | Google Trends、统计、协会、公开报告、价格平台、指数/期货入口 | 不做商业建议 |

Source Pack 只是“去哪里找”的目录，不是事实库。每次报告仍要打开来源、记录日期和生成 EvidenceCard。

## 11. 采集完成度分级

| 等级 | 条件 | 用户可见说法 |
|---|---|---|
| `plan_only` | 无搜索或来源打开能力，或缺关键产品/目的国 | 已形成采集计划，尚未核实来源 |
| `source_limited` | 只有用户给的少量来源，无法覆盖全部事实域 | 基于已给来源的局部分析 |
| `partial_matrix` | 部分事实域有 EvidenceCard，部分未执行/来源受限 | 部分模块已核实，部分待确认 |
| `ready_with_limitations` | 核心来源打开，缺口和限制清楚 | 可交付客观参考矩阵 |
| `needs_professional_confirmation` | 税费/合规/运输需要专业确认 | 可作为报关/认证/承运沟通资料 |
| `blocked_needs_input` | 缺 SDS、UN38.3、BOM、标签、起运资料等关键文件，无法继续 | 需用户补资料后再推进 |

## 12. 阻断与停止规则

| 情况 | 处理 |
|---|---|
| 只有搜索摘要，无打开来源 | 停在候选线索，不交付已核实事实 |
| 官方来源和二级解释冲突 | 标有冲突待复核，优先官方但不强行下结论 |
| 产品版本不一致 | 打回 Brief，不继续套用法规/税费 |
| 税则候选过粗 | 不计算最终税率，只列归类缺口 |
| 技术资料缺失影响安全/运输 | 合规和物流模块降级为待技术资料确认 |
| 需要登录/付费墙 | 标来源受限，只写可见内容 |
| 来源日期过旧但用户要最新 | 要求重新复核，不称最新 |
| 出现价值判断或客户名单 | 退回改写，保持产品市场分析边界 |
