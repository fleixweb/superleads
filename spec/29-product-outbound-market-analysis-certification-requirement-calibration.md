# 产品出海市场分析：目的国认证 / 准入要求判断纠偏（Slice W）

本文件冻结产品出海市场分析里“认证”的正确业务口径。它不是代码实现，不联网查询，不给任何国家或品类的当前认证结论。

一句话：**认证分析的第一任务不是等用户提供证书，而是根据产品属性和目标国家/地区，查清该产品进入目标市场可能需要哪些认证、测试、注册、标签、包装或准入文件；用户有没有证书只是第二层材料匹配状态。**

## 1. 为什么要纠偏

真实外贸用户经常不知道自己缺什么文件。用户问“这个产品出口到美国/欧盟/沙特/越南需要什么认证”，并不代表他已经知道要提供 CE、FCC、UL、FDA、SDS、UN38.3、REACH、RoHS、CPSIA、EPR 或其它材料。

因此，Superleads 不能把认证模块做成：

```text
用户提供证书 -> 系统判断证书是否可用
```

正确流程应是：

```text
产品属性 + 目标国家/地区 + 出口国/原产国/用途/渠道条件
-> 查询目标市场准入与认证/测试/注册/标签/包装要求
-> 列出可能需要什么、什么条件下需要、依据是什么、用户现在缺什么
-> 用户提供证书后，再做证书范围匹配和材料状态判断
```

## 2. 两层对象必须拆开

| 层级 | 业务问题 | 用户可见表述 | 不得混写 |
|---|---|---|---|
| 目标国准入要求 | 这个产品进入/销售/清关到目标国家或地区，可能需要哪些认证、测试、注册、标签、包装或准入文件？ | `目标市场要求：待查/已核实/条件性适用/不适用/无法核实` | 不得因为用户没给证书就写不需要认证 |
| 用户材料状态 | 用户现在有没有对应证书/报告/声明/标签图/BOM/SDS/UN38.3？是否覆盖本型号、标准、国家、批次和用途？ | `用户材料状态：未提供/已提供待核/匹配当前范围/不匹配/未知` | 不得因为用户给了证书就写目标国已认可或产品已合规 |

COO / 原产地证明已经按这个逻辑拆开；认证、测试、标签、注册也必须同样拆开。

## 3. “认证”不是一个单一文件

用户说“认证”时，系统要按产品和目标市场拆成更细的准入对象。不同国家、用途和渠道下，可能根本不是一张证书，而是测试报告、注册、声明、标签、技术文件、进口许可或渠道准入条件。

| 准入对象 | 可能是什么 | 示例触发项 | 用户材料可能是什么 |
|---|---|---|---|
| 强制认证 / 合格评定 | 主管机关或法规要求的认证、批准、符合性评估 | 电器、无线、电池、机械、玩具、儿童用品、医疗/健康相关产品 | 证书、Declaration of Conformity、授权代表文件、注册号 |
| 测试报告 | 按标准完成的测试，不一定等于“证书” | EMC、无线、化学限量、纺织、食品接触、儿童安全、锂电运输 | 测试报告、test summary、实验室报告 |
| 产品注册 / 企业注册 | 进口前、销售前或上市前注册 | 食品、化妆品、医疗、化学品、农产品、特定消费品 | 注册证明、账号截图、备案号 |
| 标签 / 标识 | 产品、包装或说明书上的强制信息 | 原产国、成分、警示语、能效、年龄、语言、护理标签、回收/EPR | 标签照片、包装稿、说明书、Artwork |
| 包装 / 环保 / 回收 | 包装材料、木包装、EPR、回收标识 | 电商零售、包装进入欧盟、木托盘、危险品包装 | 包装规格、材质、EPR 注册、IPPC 标识、UN 包装证明 |
| 进口许可 / 检疫 / 卫生文件 | 进口国主管机关要求的许可或证明 | 食品、农产品、植物/动物材料、花卉、茶叶、木材、危险化学品 | 进口许可证、卫生证、植检证、产地/处理证明 |
| 运输安全文件 | 运输法规或承运要求，不等于市场销售认证 | 锂电、化学品、危险品、液体、粉末、磁性、气雾剂 | SDS、UN38.3、危险品申报、包装证明 |
| 渠道/客户要求 | 法规之外，零售商、平台、项目或买家要求 | 大型零售、电商平台、政府项目、品牌客户 | 审厂、社会责任、质量体系、产品测试、保险文件 |

## 4. 目标国要求状态

| 状态 | 含义 | 可写给用户的话 | 需要什么证据 |
|---|---|---|---|
| `required` | 当前产品和场景下，目标市场规则明确要求 | `该目标市场在当前条件下要求此项认证/测试/注册/文件。` | 目标国官方/主管机构/标准机构/海关/法规来源直接支持 |
| `conditionally_required` | 只有满足某些属性、用途、销售方式、年龄段、成分、功率、无线功能、食品接触等条件时要求 | `满足这些条件时需要；条件未确认前不能下最终结论。` | 权威来源 + 明确触发条件 |
| `normally_not_required` | 在当前已知条件下，公开权威来源显示通常不要求单独认证/注册 | `当前条件下通常不要求该项；但标签、海关或客户要求仍需另看。` | 权威来源 + 排除条件 |
| `not_applicable` | 已确认该要求不适用于当前产品或场景 | `该要求不适用于当前产品/用途/路径。` | 权威来源或产品属性排除依据 |
| `unable_to_verify` | 本轮没有打开足够权威来源或产品条件不足 | `本轮无法用权威来源核实，不能写需要，也不能写不需要。` | 来源受限、未执行或关键属性缺失记录 |
| `not_executed` | 本轮没有执行该要求查询 | `本轮未执行该项认证/准入查询。` | not-executed 记录 |

## 5. 用户材料状态

| 状态 | 含义 | 用户可见写法 |
|---|---|---|
| `user_material_not_requested_yet` | 先查目标要求，暂未要求用户提供对应文件 | `暂未要求用户提供；先确认目标市场是否需要。` |
| `user_material_status_unknown` | 不知道用户是否有 | `用户材料状态未知。` |
| `user_not_provided_but_required` | 目标要求已显示需要，但用户未提供 | `目标市场要求该项，用户当前未提供，需补。` |
| `user_not_provided_and_not_required_for_current_scenario` | 目标要求显示当前场景通常不需要，且用户未提供 | `当前场景通常不要求该项；用户未提供不构成本项缺口。` |
| `user_provided_needs_review` | 用户提供了文件，但需核对范围 | `用户已提供，需核对型号、标准、国家、日期、签发机构和覆盖范围。` |
| `user_provided_valid_for_scope` | 文件已核对并匹配当前范围 | `用户文件与当前产品/国家/场景范围匹配；最终适用仍可能需专业确认。` |
| `user_provided_not_valid_for_scope` | 文件不匹配当前目标市场或产品版本 | `用户文件不覆盖本次目标市场/型号/标准/日期，不能作为当前合规依据。` |

## 6. 目标国要求行字段合同

未来实现时，产品准入与合规矩阵应允许一类独立行：`destination_requirement` / `certification_requirement`。最小字段如下。

| 字段 | 必填 | 说明 |
|---|---|---|
| `requirement_name` | 是 | 人话名称，如 `无线电设备授权`、`食品接触材料测试`、`纺织标签`、`锂电 UN38.3` |
| `requirement_family` | 是 | `certification`、`test_report`、`registration`、`labeling`、`packaging`、`import_permit`、`transport_document`、`channel_requirement` 等 |
| `destination_country_or_region` | 是 | 目标销售/进口国家或地区 |
| `applicability_status` | 是 | 使用第 4 节目标国要求状态 |
| `trigger_conditions` | 是 | 适用条件：产品属性、用途、HS 候选、销售渠道、年龄段、材料、功率、无线功能等 |
| `authority_or_source` | 是 | 目标国主管来源、官方法规、标准机构、海关、认证机构说明或来源受限状态 |
| `source_authority_level` | 是 | `primary_official`、`secondary_official`、`standards_body`、`certification_body_reference`、`professional_reference`、`source_restricted` 等 |
| `accepted_evidence_or_documents` | 是 | 证书、测试报告、DoC、注册、标签、SDS、UN38.3、进口许可证等 |
| `user_material_status` | 是 | 使用第 5 节用户材料状态 |
| `user_material_review_scope` | 是 | 若用户提供材料，要看型号、标准、国家、批次、有效期、签发主体、授权范围 |
| `gaps_and_next_steps` | 是 | 还需要用户/供应商/认证机构/报关行/承运人补什么 |
| `cannot_conclude` | 是 | 明确不能推出什么，如不能写已合规、不能替代美国要求、不能替代运输承运确认 |
| `status_label` | 是 | 人话状态：已核实 / 条件性适用 / 待技术资料确认 / 待专业确认 / 来源受限 / 未执行等 |

## 7. 来源优先级

| 问题 | 优先来源 | 次级来源 | 只能作线索 |
|---|---|---|---|
| 目标国是否要求认证/测试/注册 | 主管部门、官方法规库、海关、官方市场准入指南、标准机构 | 认证机构、合规机构、报关行/律师公开指南，标待专业确认 | 搜索摘要、平台卖家说明、模型记忆 |
| 某标准是否适用 | 官方法规引用、标准机构范围说明、主管机关指南 | 实验室/认证机构公开说明 | 同行网页、证书图片 |
| 用户证书是否匹配 | 用户文件原文、证书编号、报告页、型号、标准、日期、签发机构 | 证书查询入口、机构公开验证页 | 文件名、产品页“certificate download”入口 |
| 是否已合规 | 只有范围匹配的文件 + 目标规则 + 专业确认可支持有限表述 | 第三方报告可标待专业确认 | 单一证书入口、搜索摘要、用户口头说法 |
| 渠道/客户要求 | 平台官方 seller requirement、零售商 vendor manual、项目招标文件、客户规范 | 行业经验文章 | 泛泛“美国客户都要 UL”之类说法 |

## 8. 禁止升级规则

| 错误写法 | 为什么错 | 正确写法 |
|---|---|---|
| `用户没提供证书，所以目标国不需要认证` | 用户材料状态不能反推法规要求 | `用户未提供；目标国是否要求需按官方来源核验` |
| `用户有 CE，所以可以卖美国` | 证书国家/标准不一定被目标市场认可 | `用户有 CE 文件线索；是否覆盖美国目标场景待核验` |
| `产品页有 Certificate 下载，所以已合规` | 未读取文件范围、标准、型号、日期 | `看到证书入口；需打开文件核对范围` |
| `某认证机构文章说需要，所以官方要求已核实` | 二级解释不是主管来源 | `认证机构说明作初步参考；需官方/法规来源确认` |
| `UL/FCC/CE/FDA 之类所有产品都要` | 认证适用取决于产品属性、用途和目标市场 | `按触发条件逐项判断，未触发或未核实时保留待确认` |
| `测试报告等于认证` | 测试、认证、注册、声明是不同对象 | `测试报告只支持报告列明的测试项目` |
| `样品证书覆盖量产批次` | 文件范围可能只覆盖样品、型号或批次 | `需核对证书范围与当前 SKU/订单/批次是否一致` |
| `渠道要求等于法律要求` | 平台/零售商要求不等于海关或法规强制 | `渠道要求单列，不能写成目标国法律强制` |

## 9. 用户入口话术

当用户没提供证书时，不要先追问“你有哪些证书”。应先说明：

```text
可以。认证这块我会先按目标国家/地区和产品属性查“可能需要哪些认证、测试、注册、标签或文件”，不是等你先提供证书。你有现成证书可以发来，我会另外核对它是否覆盖本型号、目标市场和适用标准；如果没有，我会把需要向供应商/认证机构/报关行确认的材料列成清单。
```

只有当产品属性不足以判断认证路径时，才追问关键属性：是否带电/无线/电池、是否接触食品/皮肤/儿童、材质/成分、用途、规格、是否危险品/化学品、目标销售渠道等。

## 10. 用户可见输出矩阵建议

### 10.1 目标国可能要求什么

| 要求项 | 为什么可能需要 | 当前判断 | 触发条件 | 来源状态 | 用户现在要补什么 |
|---|---|---|---|---|---|
| 认证/测试/注册/标签名称 | 产品属性或目标国规则触发 | required / conditionally_required / normally_not_required / unable_to_verify | 型号、用途、材料、年龄段、渠道等 | 官方已核实 / 初步参考 / 未执行 / 来源受限 | 文件、照片、BOM、测试报告、专业确认 |

### 10.2 用户现有材料匹配情况

| 材料 | 用户是否提供 | 覆盖范围要看什么 | 当前状态 | 不能推出什么 |
|---|---|---|---|---|
| 证书/报告/声明/标签/SDS/UN38.3 等 | 已提供/未提供/未知 | 型号、标准、国家、批次、日期、签发机构 | 待核/匹配/不匹配/未知 | 不能直接推出产品已合规、目标国认可或可出运 |

## 11. 两个样本的纠偏应用

| 样本 | 正确方向 | 必须避免 |
|---|---|---|
| Xing Heng `48V20Ah` LiFePO4 电池包出口美国 | 先按锂电、电池包、960Wh、单独运输/随设备、美国目标市场和运输方式查目的国准入、运输文件、SDS、UN38.3、包装、标签、海关要求；公开 QCVN/Vietnam Register 文件只能作为已见文件范围 | 不把“证书下载入口”写成 UN38.3/SDS 已有；不因为用户没给文件就写不需要；不写可普通货/可快递 |
| UNIQLO `470177` 纺织服装出口美国 | 先按纺织服装、棉、成衣/衬衫或外套候选、美国标签/原产国标识/成分/护理/RN/可能的贸易救济路径查要求；网页信息只支持页面展示字段 | 不把网页 RN/洗护写成实物标签已合规；不把 Production: China 写成 COO；不把候选 HTSUS 写成最终归类 |

## 12. 验收断言

| 断言 | 必须满足 |
|---|---|
| W-01 | “认证”必须默认解释为目标国准入要求判断，而不是用户证书核验入口 |
| W-02 | 用户没有证书时，仍要列目标市场可能需要查的认证/测试/注册/标签路径 |
| W-03 | 用户材料状态与目标国要求状态必须分列，不得互相推导 |
| W-04 | 产品页证书入口、搜索摘要、认证机构文章不得升级为官方合规结论 |
| W-05 | 渠道/客户认证要求必须与法律/海关强制要求分开 |
| W-06 | 任何“已合规 / 不需要认证 / 可销售 / 可清关”都必须有范围匹配的权威来源和适用条件，否则降级或阻断 |
| W-07 | 输出使用人话表格：要求项、为什么可能需要、当前判断、触发条件、来源状态、用户要补什么 |
