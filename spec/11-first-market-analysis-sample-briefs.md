# 首批产品出海市场分析样本 Brief

本文件是首批两个端到端样本的输入合同，不是完整研究结论。空白、候选或“待确认”字段不得被模型依据常识补全；它们只用于触发待确认项、资料请求和条件化研究。

## 共用填写规则

| 字段状态 | 含义 |
|---|---|
| 已核实 | 本仓库已打开公开网页、抽取 PDF 或读取官方法规/税则来源并记录 |
| 已确认 | 用户已明确业务前提，但本仓库未必已有可交叉来源 |
| 派生计算 | 由已核实字段按明示公式计算，不是来源直接标注 |
| 候选 | 可作为研究路径或报关/合规讨论起点，但不能当最终结论 |
| 待确认 | 当前不能据此形成税费、合规、出口或运输确定结论 |
| 不适用 | 用户已明确该字段不适用，并说明依据 |

贸易地理字段必须分别填写：卖方所在国、出口申报国、原产国、实际起运国/城市/港口、目的国、目的港/交付地。它们相同也必须显式记录，不能默认合并。

用户给出的 ChatGPT/外部模型搜索结果只作为候选线索；只有本仓库已打开/抽取/检查的来源才能把字段标为“已核实”。

## 启动门槛

这两个真实样本已经比上一轮示范 SKU 更适合做端到端验收：产品版本、关键公开技术字段、原产/制造来源和候选税则路径都更明确。下一步可以启动“信息不足时的待确认输出”和“法规/税则/运输条件化矩阵”验收。

但只有当 UN38.3、SDS、包装方式、实际出口申报国、实际起运港/机场、最终 HTSUS 或报关归类资料得到补充后，锂电样本才能进入确定性更高的运输和税费研究；只有当实物标签、辅料/BOM、成衣规格、实际起运资料和最终 HTSUS 得到补充后，纺织样本才能进入确定性更高的标签、税费和贸易救济研究。
