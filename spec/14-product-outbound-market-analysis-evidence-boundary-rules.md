# 产品出海市场分析：证据边界校验规则（Slice 3）

本文件冻结第一版“证据边界校验规则”。它定义什么证据能支持什么用户可见表述，什么表述必须降级、阻断或退回待确认。它不是代码实现，也不新增事实来源。

## 1. Slice 3 边界

| 项目 | 本轮决定 |
|---|---|
| 目标 | 把“不能把候选/测试/网页/摘要升级成最终结论”的规则变成可检查清单 |
| 适用对象 | 对话报告、Markdown 样例、XLSX/CSV 工作簿、未来 Skill 输出 |
| 首批样本 | Xing Heng `48V20Ah` LiFePO4 电池包；UNIQLO Men's Corduroy Overshirt `470177` |
| 本轮不做 | 不写脚本、不接 evals、不新增联网来源、不生成最终市场研究报告 |
| 输出 | 证据类型、允许表述、禁止升级、降级规则、样本验收清单 |

## 2. 总体原则

| 原则 | 说明 |
|---|---|
| 只支持自己能证明的字段 | 一个来源只支持它直接显示的事实，不支持相邻结论 |
| 候选永远不是最终 | 候选 HTS、候选 UN 编号、候选运输方式都不能写成最终结论 |
| 文件范围优先于文件标题 | 必须看标准号、型号、日期、适用范围，不能只看文件名像不像 |
| 网页信息不等于实物核验 | 产品页成分、Production、洗护说明不能替代实物标签照片或进口实物审核 |
| 公开来源不等于订单文件 | 官网页面、证书、报告不能自动补齐 COO、发票、提单、装箱单 |
| 税率列示不等于最终税额 | 官方税则的基础税率只是一个税种/税号路径，最终税额还要税基、原产地、日期、10 位后缀等 |
| 未执行必须保留 | 没有采集趋势、价格、节假日、外部因素时，必须写未执行，不得编造 |

## 3. 证据类型与允许表述

| 证据类型 | 可以支持 | 不能支持 | 默认状态 |
|---|---|---|---|
| 搜索结果 / 外部模型摘要 | 候选线索、待打开 URL、待核验字段 | 已核实事实、Claim、税率、认证、原产地、运输结论 | 候选 |
| 产品官网页面 | 页面显示的产品名称、型号、参数、Production、成分等 | 实物标签已合规、最终原产地裁定、最终 HS、可运输性 | 已核实 / 候选 |
| 制造商证书 | 证书列明的型号、标准、制造商、日期、覆盖范围 | 其它标准、其它国家认证、SDS、UN38.3、最终海关归类 | 已核实 |
| 测试报告 | 报告列明的测试标准、测试对象、样品型号、测试结果 | 未列标准下的合规、承运接受、最终进口准入 | 已核实 |
| SDS / MSDS | 化学/危险品分类、运输信息线索 | 替代 UN38.3、包装、承运人接受、最终法规判断 | 已核实 / 待专业确认 |
| UN38.3 test summary/report | 锂电运输核验关键文件 | 替代 SDS、包装、UN 编号具体情形、承运确认 | 已核实 / 待专业确认 |
| 官方法规 | 法规条文、适用条件、要求路径 | 产品已经满足要求 | 已核实 / 待技术资料确认 |
| 官方税则 | 候选税号描述、税率列示、脚注 | 最终归类、最终税率、最终税额 | 候选 / 待专业确认 |
| 实物标签照片 | 照片可见标签文案和位置线索 | 标签完全合规、材质真实、所有批次一致 | 已核实 / 待专业确认 |
| COO / 发票 / 提单 / 装箱单 | 对应订单/批次的原产、起运、数量、包装线索 | 泛化到所有 SKU、主管机关最终裁定 | 已核实 / 待专业确认 |
| 公开价格页面 | 挂牌价、币种、规格、观察日期 | 成交价、传统 B2B 采购价、推荐报价 | 初步参考 |
| Google Trends | 相对搜索兴趣 | 销量、GMV、进口量、采购需求 | 已核实 / 初步参考 |

## 4. 升级禁止规则

### 4.1 锂电与危险品

| 规则ID | 如果看到 | 不得输出 | 正确输出 |
|---|---|---|---|
| EB-LB-01 | Vietnam Register / QCVN 91 证书或测试报告 | `已具备 UN38.3` | `QCVN 91 文件已见；UN38.3 待技术资料确认` |
| EB-LB-02 | 产品页写 Lithium-ion / LiFePO4 | `不是危险品`、`可普通货运输` | `触发锂电运输核验，需 UN38.3、SDS、包装资料` |
| EB-LB-03 | 48V × 20Ah = 960Wh | `可按小型锂电例外` | `派生 960Wh，超过 100Wh 小型电池门槛，例外路径不能直接使用` |
| EB-LB-04 | HMT 中有 UN3480 / UN3481 | `UN 编号固定为 UN3480` | `单独电池包候选 UN3480；随设备/装入设备按 UN3481 判断` |
| EB-LB-05 | 未见 SDS | `无需 SDS` | `SDS 待技术资料确认` |
| EB-LB-06 | 未见包装方式 | `可空运/快递/拼箱` | `运输方式待确认，需包装、文件和承运条件` |

### 4.2 纺织与标签

| 规则ID | 如果看到 | 不得输出 | 正确输出 |
|---|---|---|---|
| EB-TX-01 | 产品页写 Body/Trim 100% Cotton | `全成分 100% 棉`、`无动物材料` | `Body/Trim 已核实；辅料/BOM 待确认` |
| EB-TX-02 | 产品页写 Production: China | `实物原产标识已合规` | `网页 Production 已核实；实物 country of origin marking 待核验` |
| EB-TX-03 | 产品页写 RN 与洗护 | `纺织标签已完全合规` | `网页披露 RN/洗护；实物标签照片待核验` |

| EB-TX-05 | 未见重量/克重 | `按常见克重估算` | `重量/克重待技术资料确认` |
| EB-TX-06 | 未见辅料 | `辅料不影响合规` | `辅料/BOM 待确认，不能排除受管制材料风险` |

### 4.3 HS / HTS 与税费

| 规则ID | 如果看到 | 不得输出 | 正确输出 |
|---|---|---|---|
| EB-TAR-01 | 官方税则列出候选税号和 General 税率 | `最终税率就是 X%` | `基础税率列示为 X%；最终税率待专业确认` |
| EB-TAR-02 | 税则有 Chapter 99 脚注 | `一定适用/不适用附加税` | `Chapter 99 脚注待核验，需最终 HTSUS、原产地、报关日` |
| EB-TAR-03 | 只有 6/8 位候选税号 | `最终 10 位税号已确定` | `10 位统计后缀待确认` |
| EB-TAR-04 | 原产地是公开页面线索 | `可直接计算最终税额` | `正式税费需原产地文件/规则、税基和有效税表` |
| EB-TAR-05 | 缺少税基 | `应缴税额为某金额` | `税额未计算，税基待确认` |

### 4.4 原产地、出口与起运

| 规则ID | 如果看到 | 不得输出 | 正确输出 |

| EB-ORI-02 | 证书列出制造商/装配厂地址 | `实际起运港已知` | `制造/装配地已知；实际起运港/机场待确认` |

## 5. 降级与阻断规则

| 情况 | 处理方式 | 用户可见写法 |
|---|---|---|
| 来源直接支持字段 | 标 `已核实` | `已核实：来源显示...` |
| 来源只支持方向 | 标 `候选` 或 `初步参考` | `候选：可作为下一步核验方向` |
| 缺技术文件 | 标 `待技术资料确认` | `需补 SDS / UN38.3 / BOM / 标签图` |
| 缺订单/起运信息 | 标 `待业务确认` | `需补提单、装箱单、出口申报国、起运港` |
| 需要专业判断 | 标 `待专业确认` | `需报关/认证/承运人/主管机关确认` |
| 来源之间冲突 | 标 `有冲突待复核` | `来源 A 与来源 B 不一致，暂不下结论` |
| 未执行该模块 | 标 `未执行` | `本轮未采集，不能形成结论` |
| 出现禁止升级表述 | 阻断交付或退回改写 | 改为对应“正确输出” |

## 6. 用户可见敏感词 / 禁止短语清单

这些短语在产品出海市场分析交付中默认应被拦截，除非后面明确带有“不得/不能/禁止”等否定语境。

| 类别 | 禁止短语示例 |
|---|---|
| 市场价值判断 | 值得进入、建议进入、市场潜力高、推荐开发、优先开发 |
| 税费无条件结论 | 最终税率就是、应缴税额为、一定适用附加税、无需关税 |
| 锂电错误升级 | 已具备 UN38.3、无需 SDS、普通货运输、可直接空运、可直接快递 |
| 纺织错误升级 | 标签已完全合规、全成分无动物材料、一定归 6205.20.20 |
| 物流承诺 | 最佳运输方式、保证时效、承诺交期、一定可以拼箱 |
| 市场未采集结论 | 销量增长、采购需求旺盛、旺季确定、最新影响显著 |

## 7. Slice 3 样本特定断言

### 7.1 Xing Heng `48V20Ah` 必须通过

| 断言ID | 必须满足 |
|---|---|
| XH-EB-01 | 报告中 `UN38.3` 只能是 `待技术资料确认`，除非新增对应 UN38.3 文件来源 |
| XH-EB-02 | `SDS` 只能是 `待技术资料确认`，除非新增对应 SDS 来源 |
| XH-EB-03 | `Vietnam Register / QCVN 91` 只能支持证书/测试范围，不能支持 UN38.3 或美国认证 |
| XH-EB-04 | `960 Wh` 必须标 `派生计算`，不能写成厂商单独标注 |
| XH-EB-05 | `8507.60.00` 必须标 `候选` 或 `待专业确认`，不能写最终 HTSUS 已确定 |
| XH-EB-06 | `General 3.4%` 只能作为基础税率列示，不能写最终税率 |
| XH-EB-07 | 起运港/机场必须保持待确认，不能默认海防港或其它港口 |
| XH-EB-08 | FCL/LCL/空运/快递只能是候选方式，不能写可出运或最佳方式 |

### 7.2 UNIQLO `470177` 必须通过

| 断言ID | 必须满足 |
|---|---|
| UQ-EB-01 | `Production: China` 可标已核实，但制造工厂和起运港必须待确认 |
| UQ-EB-02 | Body/Trim 100% Cotton 可标已核实，但辅料/BOM 必须待确认 |
| UQ-EB-03 | RN 与洗护说明可标网页已核实，但实物标签必须待实物核验 |
| UQ-EB-04 | 不能写标签已完全合规，除非有实物标签和专业核验依据 |
| UQ-EB-05 | `6205.20.20` 必须标 `候选` 或 `待专业确认`，不能写一定归类 |
| UQ-EB-06 | `General 19.7%` 只能作为基础税率列示，不能写最终税率 |
| UQ-EB-07 | 单件重量/克重必须待技术资料确认，不能估算 |
| UQ-EB-08 | 运输方式只能是候选组织方式，不能推荐最佳方式 |
