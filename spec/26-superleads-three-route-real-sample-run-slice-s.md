# Slice S：Superleads 三条路线真实外贸样本跑通

日期：2026-07-27

## 1. 本 Slice 要解决什么

Slice R 已经确认：Superleads 不能继续围绕内部证据层空转，必须回到真实外贸业务动作。

本 Slice S 的目标不是新增功能代码，而是用三条真实外贸任务各跑一份**用户可见样本**，检查 Superleads 现在看起来是不是一个外贸人能用的产品。

三条路线分别是：

| 路线 | 样本任务 | 交付形态 |
|---|---|---|
| 批量客户开发 | 中性包装柴油发电机后市场配件，美国，维修商/零件渠道/经销商 | 发现候选池样表 |
| 单一客户背调 | Chilly's / CHILLY'S BOTTLES LIMITED | 表格化客户背调报告 |
| 产品出海市场分析 | Xing Heng 48V20Ah LiFePO4 电池，越南原产/制造线索，出口美国 | 产品市场与准入信息矩阵 |

## 2. 本轮共同边界

| 项目 | 边界 |
|---|---|
| 是否写代码 | 不写功能代码 |
| 是否做正式客户交付 | 不做正式交付，只做产品样本验收 |
| 是否替用户判断商业价值 | 不判断 |
| 是否生成推荐客户/推荐市场 | 不生成 |
| 是否保留弱证据 | 保留，但降级显示 |
| 是否把搜索摘要当事实 | 不允许；只有打开的公开来源或既有可复核样本来源才能入表 |
| 是否暴露内部对象名 | 用户样本中不暴露 graph、EvidenceCard、SearchLog、Claim、rule id 等内部语言 |

## 3. 通过标准

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| S-01 | 三条路线是否分清 | 批量找客户、单客背调、产品市场分析互不串线 |
| S-02 | 用户是否一眼看懂 | 优先表格、短句、人话字段，不用内部对象名 |
| S-03 | 弱证据是否保留 | 候选、可能相关、待确认、未执行、来源受限均可见 |
| S-04 | 是否避免价值主张 | 不写“值得进入”“优先推荐”“最佳路线”“必然成交” |
| S-05 | 是否减少真实误导 | 不把平台价当成交价、候选税号当最终税率、网页信息当实物核验、公开入口当采购意愿 |
| S-06 | 是否能指导下一步 | 每条样本都有“还缺什么/下一步确认什么” |

## 5. 对后续路线的影响

Slice S 通过后，下一步不应立刻回到纯内部对象层，而应优先做能改善用户可见交付的实现切片，例如：

1. 将三条路线样本固化为可回归的 Markdown / CSV 输出验收；
2. 把“用户可见表格是否说人话”做成静态检查；
3. 再考虑是否需要 EvidenceCard 草稿前人工复核队列。

如果某个后续代码 Slice 无法说清楚它改善了哪张用户可见表、减少了哪类真实外贸误导，应暂缓。
