# 批量客户开发样本：美国柴油发电机后市场配件

## 开场四行

| 开场字段 | 人话表达 |
|---|---|
| 我理解你卖的是 | 中性包装柴油发电机后市场配件 |
| 本次优先找 | 美国做发电机维修、柴油/工业发动机备件、发电机经销或服务的公司 |
| 本次不纳入 | 原厂 OEM、纯制造商、明显不在美国市场的主体、只做普通汽车零售且无发电机/工业柴油线索的主体 |
| 判断依据将重点看 | 官网是否出现 generator / diesel engine parts / service / quote / parts & accessories / power generation 等公开信号，以及是否有可联系入口 |

## 交付边界

| 要注意什么 | 为什么 |
|---|---|
| 候选池不是正式开发名单 | 还需要继续打开来源、去重、补联系人归属和业务范围 |
| 联系入口不等于采购意愿 | Contact、Quote、Wholesale 只能说明有公开沟通入口 |
| 弱线索不删除 | 可能相关和边界线索保留给用户判断是否继续核查 |
