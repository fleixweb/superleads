## 2. 来源策略验收

| 验收项 | 检查结果 | 说明 |
|---|---|---|
| 搜索摘要不能变事实 | 通过 | 搜索只产生候选线索 |
| 打开来源才形成 Observation | 通过 | 需要 URL/文件、定位、摘录、日期 |

| 能力不足会降级 | 通过 | 缺 search/source/document/render/Trends 均有降级写法 |

| 不暴露内部信息 | 通过 | 用户来源表不得有本地路径、hash、内部 ID、token URL |

| 事实域 | 检查结果 | 说明 |

| 物流与申报节点 | 通过 | FCL/LCL/快递/空运/铁路/散杂/RoRo/冷链均覆盖，时效非承诺 |
