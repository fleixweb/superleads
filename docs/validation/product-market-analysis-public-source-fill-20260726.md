## 5. 这次试跑得到的产品设计结论

| 结论 | 对产品出海市场分析模块的影响 |
|---|---|
| 公开目录足以补齐大量技术字段，但通常不足以证明 SKU 级原产地 | 输入模型必须把“工厂/办公室/出货地线索”和“原产地证明”分开 |
| 锂电样本可以从公开目录抽到 V、Ah、尺寸、重量、化学体系线索 | 可启动锂电属性触发矩阵，但运输/危规/税费仍需要 UN38.3、SDS、包装方式和 HS |
| 纺织样本可以从 TDS 抽到成分、克重、织法、门幅、质量指标 | 可启动纺织属性触发矩阵，但 HS、标签、贸易救济不能只凭“纺织品”输出 |
| 官网页面之间可能出现证书数量/证书文字不一致 | 交叉复核 Skill 必须保留冲突，不得选择性忽略 |
| 原产地是贸易文件事实，不是品牌官网存在某国工厂即可推出 | 报告中需要专门设置“原产地证据等级” |
