# Slice S 验收样本：三条 Superleads 路线真实外贸任务跑通

日期：2026-07-27

## 0. 本轮说明

这不是正式客户交付，而是产品内核校准样本。目标是看 Superleads 的三条路线是否已经能用外贸人能理解的方式表达：

1. 批量客户开发：给候选客户池，不替用户筛成“推荐客户”。
2. 单一客户背调：围绕一个指定对象说清它是谁、公开做什么、怎么联系、还缺什么。
3. 产品出海市场分析：围绕一个产品和目标国家/地区，列市场、准入、税费、物流、出口和待确认项，不生成客户名单，不判断值不值得进入。

本轮用到的来源均为公开网页线索或仓库内已保留的公开来源样本；搜索摘要不写成事实。批量客户开发样表是用户可见交付形态校准，不是正式开发名单；若进入正式交付，需逐条重新打开来源、记录可复核页面和观察日期。
