# 批量客户开发 L2 用户可见 Markdown 版式

本文件是 `standard_development_list` 在脚本不可执行时的逐字版式所有者。它只规定用户可见投影，不放宽图谱、来源、主体、联系人、Review、Audit 或标准名单准入门禁。

## 段落顺序

1. `标准开发名单说明`
2. `客户信息总表`
3. `联系方式汇总`
4. `公开信息与待核查事项`
5. `官网与来源链接`
6. `待核查事项`
7. `风险与说明`
8. `下一步可选`（执行状态提供菜单项时输出）

六张业务表的列顺序必须使用官方工作簿投影的列顺序。下列列名是当前 canonical 投影；若官方 exporter 的 sheet schema 发生变更，必须同步修改本文件、ownership marker 和回归测试。
