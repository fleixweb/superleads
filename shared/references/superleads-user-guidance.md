# Superleads 用户引导规则

`scripts/superleads_user_guidance.py` 的 `_GUIDE_CONTENT` 是唯一业务内容模型，负责程序化渲染和终态支持安全尾注；`skills/using-superleads/SKILL.md` 的裸启动与详细帮助代码块是零工具的内联投影。两处由一致性测试约束，不维护独立英文 Skill、帮助文件或 locale。

首次仅调用 `@superleads` 时，逐字返回 `SKILL.md` 内联的对应语言紧凑静态引导。询问“你能干嘛”“怎么用”“如何使用”“帮助”“新手入门”及相同含义的英文问题时，逐字返回其中的详细静态引导；详细引导包含“更多用法”及导出表格说明。不调用 shell、搜索、预检或研究流程，不展示 JSON、路由名称或其他内部字段。

这条帮助路径是静态回复：不搜索、不打开来源、不做能力检查、不检查版本、不扫描旧缓存、不导出、不验证，也不创建研究记录。用户已经给出明确找客户需求、指定公司或资料、产品和目标市场分析要求，或上传表格并说明补全、导出、核查任务时，直接进入原有流程，不先展示完整引导。

语言只改变表达，不改变三类入口、最低输入字段、示例结构、证据边界、决策限制或支持安全提醒。中文使用中文，英文使用英文；其他语言尽量使用用户语言，无法完整表达时优先保持业务边界准确。

终态用户交付、能力受限终止说明和资料初审完成时，调用 `append_final_footer()` 追加一次统一可见尾注。最终对话答复本身也是终局交付：追加尾注后，必须用 `validate_superleads_user_visible_output.py` 按当前路线和交付层级检查完整答复。它与导出 Markdown 遵守同一路径和附件约束：只说文件名和文件类型，不写盘符、绝对路径、目录层级或 `file://` URL，不手工构造宿主文件指令。中间进度和单独澄清问题不调用尾注，但同样不得暴露内部运行时细节。任何用户可见内容不得包含 HTML 注释定界符；尾注本身不搜索、不联网、不检查版本，也不扫描缓存。

批量开发客户的默认结果是带来源和待确认项的候选客户池，不是开发优先级建议或正式开发名单；不假设客户画像、规模、渠道、采购意图或目标平台。单一客户背调保持用户指定对象范围，不因名称相似合并不同公司。目标市场分析不自动生成客户名单，不替用户决定是否进入市场；型号、规格、原产国或税号不明确时保留为待确认项。补全客户表以用户上传表格为范围，联系人核查只基于公开来源和公开企业关联信息。
