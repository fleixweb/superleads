# 批量客户开发 L1 用户可见 Markdown 版式

本文件是 `initial_lead_list` / 发现候选池在脚本不可执行时的逐字版式所有者。段落名、顺序、表头和固定说明必须与 `scripts/export_superleads_markdown.py` 一致；不得用工作簿 sheet 名自行拼装报告。

## 默认段落顺序

1. `先把开发方向说清`
2. `发现候选池样表（候选池不是正式开发名单）`
3. `本轮搜索组合`（条件段：当前 Run 存在可展示的搜索组合时输出）
4. `尚未覆盖的组合（可继续）`（条件段：当前 Run 存在已记录的未覆盖组合提示时输出）
5. `联系方式汇总`
6. `搜索覆盖与收敛`
7. `待确认事项`
8. `已排除 / 仅作参考`
9. `信息从哪里来`
10. `风险与说明`
11. `下一步可选`（达到候选池交付边界且执行状态提供菜单项时输出）

默认 L1 **整段省略** `社媒与公开职业线索`、`地图与经营地址`、`第三方贸易摘要`。这些类别仍在候选表或待确认项中标为“未核验”；不得为了避免空值输出三个空壳段落。

只有用户明确要求“补社媒 / 地图 / 贸易记录信号”时，才在 `联系方式汇总` 之后、`搜索覆盖与收敛` 之前，按以下固定顺序插入三个补充段落：

1. `社媒与公开职业线索`
2. `地图与经营地址`
3. `第三方贸易摘要`

该补充路径仍是 L1 候选池；会记录每条公开信号的主体关联状态，但不做深度联系人归属核验或正式资格审核，不升级为标准开发名单。
