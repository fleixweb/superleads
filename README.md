# Superleads：外贸客户开发、客户背调与出口市场分析

**中文（GitHub 首页）** | [English](README.en.md)

> 面向外贸工厂、贸易公司、外贸 SOHO 和出口销售团队的智能助手：开发海外客户、研究进口商与经销商、背调指定公司，并分析产品出口市场。

Superleads 是一套基于公开证据的外贸业务研究工具，帮助外贸团队开发海外客户、研究进口商和经销商、背调公司与品牌，并分析产品出口市场。它支持 Claude、Codex、ChatGPT 和 Hermes，要求明确区分已核实信息、候选线索、待确认事项、来源受限和本轮未执行内容。

## 适合谁

- 传统外贸工厂、出口贸易公司、外贸 SOHO、品牌出海团队和企业销售团队。
- 正在开发进口商、经销商、批发商、零售连锁、品牌客户、项目客户或代工客户的人。
- 想在报价、开发或参加展会前，先看清客户、产品、国家、准入、税费和物流边界的人。

## 你可以用 Superleads 做什么

### 批量开发海外客户

按产品、目标国家、渠道和客户类型寻找进口商、经销商、批发商、零售商、品牌商、项目客户和代工客户，输出候选客户池、公开业务信号、官网、来源、公开联系入口和待核查项。

### 背调一个公司或品牌

核对公司、品牌、官网、实际业务、产品匹配、公开联系人和联系方式；识别同名公司、错配官网、关联方、竞争对手和风险项。

### 分析产品出口市场

围绕一个产品和目标国家/地区，整理公开市场资料、Google Trends 长期搜索兴趣、价格参考、准入合规、认证/测试/注册/标签、原产地证明、进口税费、出口国要求、物流路线和近期外部因素。

### 补全已有资料

读取已有客户表、官网、产品手册、目录、展会名录或公开材料，保留原始信息后再去重、补充和复核。

## 为什么结果更可靠

- 每条重要信息尽量保留公开来源、联系人归属和判断依据。
- 搜索摘要只能作为发现线索，不直接升级为事实结论。
- 候选客户不等于已确认买家，公开联系人也不等于采购负责人。
- 资料不足时明确标记候选、待核实、来源受限或未执行，而不是把猜测包装成销售结论。

正式客户开发、客户背调和产品出海市场分析需要当前智能助手同时具备联网搜索与打开可记录来源的能力。若当前环境缺少其中任一能力，Superleads 会明确要求切换环境，不会把“搜索计划”或空报告当作正式交付。

产品出海市场分析会把默认出口申报国、原产国/制造来源、实际起运地/起运港分开记录；目标国是否要求原产地证明、认证、测试、注册、标签或包装文件，会按公开权威来源判断，不会根据“手头已有证书”反推法规要求。

## 开始使用

你不需要懂技术或命令。打开正在使用的智能助手，新开一个对话，复制对应文字并允许它完成安装即可。若智能助手没有安装权限，它应明确告诉你需要确认哪一项权限，而不是让你自己猜设置。

### Claude Code

```text
请帮我安装 Superleads 官方插件。使用官方仓库 https://github.com/fleixweb/superleads 添加 Superleads 插件市场，然后完成安装。安装后请确认 Superleads 已启用。若需要系统权限，请先告诉我要确认什么；不要修改我的项目文件。
```

### ChatGPT、Codex 应用和 Codex 命令行工具

ChatGPT、Codex 应用和 Codex 命令行工具共用同一个 Codex 环境，无需重复安装。

```text
请在当前 ChatGPT 或 Codex 环境安装 Superleads。使用官方仓库 https://github.com/fleixweb/superleads 完成安装，并确认 Superleads 已启用。若需要权限，请先说明需要我确认什么；不要修改我的项目文件。
```

### Hermes

```text
请把官方仓库 https://github.com/fleixweb/superleads 作为完整的 Superleads 技能包安装到当前 Hermes 环境。安装后请确认 Superleads 的客户开发、客户背调和市场分析功能可以使用；若需要权限，请先说明。
```

### TraeWork

```text
请帮我安装 Superleads 官方插件。使用官方仓库 https://github.com/fleixweb/superleads 完成安装，并确认 Superleads 已启用。若需要系统权限，请先告诉我要确认什么；不要修改我的项目文件。
```

## 安装后怎么开始

安装完成后，不需要学习命令或研究复杂设置，直接把下面任意一句话发给正在使用的智能助手，再把方括号里的内容换成你的实际情况即可。

### 想开发一批海外客户

```text
我生产或销售 [产品]，想开发 [国家/地区] 的进口商和经销商。请优先寻找官网能确认相关业务的公司，排除明显不匹配的企业，并整理候选客户、官网、公开联系方式、信息来源、适合的开发切入点和仍需核实的地方。不要把未核实线索当成事实。
```

### 想先了解一个客户

```text
我准备联系这家公司：[公司名/官网]。请帮我查清它主要做什么、是否经营 [产品]、可能属于哪个主体、有哪些公开联系入口，以及跟进前需要确认的风险。所有判断请保留来源，不能把搜索摘要当成事实。
```

### 想了解产品能否进入一个市场

```text
我想把 [产品/型号] 卖到 [国家/地区]。请先帮我了解这个市场的公开需求信号、价格参考、进口准入、认证和标签、原产地证明、税费以及物流要求。已知出口国是 [中国/其他国家]，原产国是 [已知则填写]。请只整理客观资料和待确认事项，不要替我判断是否值得进入。
```
